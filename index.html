Placement test · diagnostic assessment

Think Placement Test

Пройди диагностический тест, чтобы определить стартовый уровень английского и получить персональный учебный маршрут.

Тест занимает до 80 минут. Результат и профиль навыков будут переданы в личный кабинет после завершения. Открытые ответы и диктант могут требовать проверки преподавателем.
Режим разработки
Для проверки кабинета можно подставить демонстрационный результат и не проходить тест заново.
DEV TOOLS
